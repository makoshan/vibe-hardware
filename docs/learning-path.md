# 六关学习路径

按顺序做。每一关只增加一个概念。

## 第 1 关：点亮

让开发板上的灯闪烁。

学会：连接开发板、选择串口、编译烧录、查看串口日志。

## 第 2 关：输入与输出

按钮控制 LED，旋钮调节亮度。

学会：数字输入、数字输出、模拟量读取、PWM。

## 第 3 关：读取传感器

连接 BME280 或 VL53L0X，串口打印测量结果。

学会：3.3V / GND、I²C、调用传感器库。

## 第 4 关：显示结果

把温度、距离或网络状态显示在屏幕上。

学会：SPI、文字与图形、简单状态界面。

## 第 5 关：灯光反馈

根据距离、温度或 AI 结果改变 RGB 灯环颜色。例如：

- 蓝：等待输入
- 黄：AI 处理中
- 绿：任务完成
- 红：连接失败

## 第 6 关：语音交互

最小语音链路：

1. 按下按钮  
2. INMP441 开始录音  
3. ESP32 将音频发送到服务端  
4. AI 生成回复  
5. 屏幕显示文字  
6. 喇叭播放语音  

## 验收口诀

先完成 **一个输入 + 一个输出**：

- 按钮 → 灯  
- 传感器 → 屏幕  
- 麦克风 → AI → 喇叭  

基础链路工作后，再加外壳、动画和更多传感器。

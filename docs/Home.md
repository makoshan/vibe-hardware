# Vibe Hardware 入门地图

目标不是学完整电子工程，而是几小时内跑通：

**传感器输入 → ESP32 处理 / 调用 AI → 屏幕、灯光或声音反馈**

## 三层材料（别混在一起）

| 层 | 用途 | 本仓库 |
|---|---|---|
| 1. 入门地图 | 讲清路线、套件、工具、安全 | `docs/`（你正在看的） |
| 2. 工作坊 | 2 小时现场：集成板或面包板 + 六关 | [学习路径](learning-path.md) |
| 3. 进阶制造 | PCB、外壳、打板、小批量 | [工具地图](tools.md) 后半 |

一份 26 页 PPT 很难同时当课程、操作手册和制造指南。这里把地图拆开。

## 一条真实路线

需求描述 → AI 辅助拆解 → **开发板验证** → 固件 → PCB → 外壳 → 打板与打印 → 实物验收

黑客松 / 工作坊通常交付到「开发板验证 + 固件」。PCB 与开模是后半段。

## 简化原则

- 每人只配**基础包**
- 麦克风、喇叭、屏幕、NFC **按小组共享**
- 项目定了再加摄像头、电机或电池

## 需求拆解与功能验证

把一句产品目标变成可重复的输入、处理和输出。先完成已有六个接口实验，再做本章。

交付物：一页需求、模块 BOM、引脚表、三次重复测试记录。

### 练习项目：桌面提醒器

教学目标示例：让桌前工作的人按一下按钮开始专注，到时能看见提醒；断电后明确回到待机。先用 USB 供电，电池作为后续选修。这里的尺寸、成本和测试阈值都是练习设定，不是已验证商品指标。

写下用户、场景、核心动作与通过标准。例如：普通室内、桌面 50 cm 阅读、按键后 200 ms 内有视觉反馈、到时显示 DONE。延迟目标由你测量确认。

1. 画四格：用户困扰 → 按下开始 → 看到运行中 → 到时确认。找一位使用者复述，确认真正需要提醒而不是复杂日程管理。
2. 列必须有的能力：一个按键、屏幕、计时、复位；把联网、语音、手机 App 放到独立需求行，写明它解决什么问题再决定。
3. 把每项能力对应到模块、接口、电压、驱动示例和验收项；没找到数据手册或示例的模块先不进入购买清单。

### 搭原型的顺序

1. 先跑主控 Blink 和串口；保存成功固件、板型与库版本。
2. 单独接按钮，再单独跑屏幕厂商示例；每加一个模块都先断电。
3. 共地后合并两个示例，列出所有 GPIO，检查 SPI、背光、按钮是否复用或冲突。
4. 用短时间提醒（例如 5 秒）重复三次完整流程；再改成实际时长，记录真实耗时。
5. 拔掉再接上 USB，验证启动状态明确；人为断开屏幕前先断电，检查重新上电时能报故障，而非显示假成功。

## 读手册、电路与返修

补上从模块原型走向自制 PCB 所需的电路判断。PCB 与 SMT 的具体操作继续使用现有制造教程。

交付物：器件核对表、测量记录、通过检查的原理图与制造文件。

### 读一份手册：先找这六处

1. 确认完整料号、封装后缀、手册版本；开发板引脚号不等于芯片焊盘号。
2. 找 Recommended Operating Conditions 或正常工作条件，记供电和工作温度；Absolute Maximum 是损坏边界，不能当设计工作点。
3. 查引脚功能与上下电约束：输入是否容忍 5V、启动绑带脚能否接按钮、是否需要外部上拉。
4. 查电气特性：输入高低阈值、输出驱动能力、待机和峰值电流；记录测试条件，不能只抄典型值。
5. 查 Typical Application、布局建议与机械图，把去耦、电源、参考地、天线禁入区和封装尺寸一起带到 EDA。
6. 把每个关键结论写成“手册页码／条件／采用值／实测结果”；出现不同版本冲突时回到准确料号。

### 模拟电路：用万用表验证分压与 RC

以下是低压独立练习。先不接 ADC，用断电测阻与上电测压确认接线；ADC 上限还受芯片、衰减和板级电路影响。仿真可以先观察趋势，不能替代实测。

1. 两只 10 kΩ 电阻串接在 3.3 V 与 GND 之间，万用表测中点；理想值 1.65 V。记录实际供电及阻值，按 Vout = Vin × R下 / (R上 + R下) 比较。
2. 中点对地并联 1 µF 电容，注意极性与耐压。理想等效电阻约 5 kΩ，时间常数约 5 ms；用示波器观察启动趋势，普通万用表不适合判断毫秒过程。
3. 理解负载：接入 ADC 后重新测中点；若采样结果偏移，检查采样阻抗、参考、衰减和校准，必要时按芯片建议加缓冲或降低分压阻值。
4. 保存原理图与测量条件；把同一电路画入已有电路仿真工具或 Falstad，比较理想模型与真实元件差异。

[Falstad 电路模拟器](https://www.falstad.com/circuit/)

### 数字信号与双层 PCB 的入门判断

回流路径是信号电流返回源头的路径。即使 SPI 时钟不高，快速边沿也可能对长线和不连续参考地敏感。先依据芯片设计指南布局，再根据测量修改。

1. 按电源、主控、接口分区；去耦紧靠相应电源脚，缩短电源到电容再到地的回路。
2. 尽量保留连续地参考，别让关键线跨地平面裂缝；布完后重铺铜、检查孤岛和未连接网络。
3. SPI 时钟与数据保持短且有参考地，远离开关电源节点；天线禁入区按所用模组手册执行。
4. 逻辑分析仪看命令、字节与时序；示波器用短接地测边沿、过冲和供电跌落。逻辑解码正确不代表电气波形合格。
5. USB、射频、高电流及四层板按准确芯片指南和板厂层叠设计。四层可从信号／地／电源与慢信号／信号的分层思路学习，但阻抗、回流与跨层过孔必须由实际层叠复核。

[EDA → PCB → SMT 实操](https://vibe-hardware.v2eth.workers.dev/manufacturing)

### 手焊、热风与故障返修

1. 从废板或焊接练习板开始，断开 USB 和电池，固定板、准备耐热垫与局部排烟；不在带电板上拆焊。
2. 用烙铁同时加热焊盘和引脚后送锡；不要靠堆锡掩盖未润湿。检查虚焊、桥连和方向。
3. 桥连先加适量电子助焊剂并用吸锡带处理；避免反复长时间加热拉脱焊盘。
4. 热风拆件先确认周围塑料、连接器和敏感元件耐温，保护邻件；温度、风量、预热与时间按设备、焊料和器件资料设定。焊锡充分熔化才轻取，不硬撬。
5. 回流焊使用与锡膏、器件匹配的曲线和测温验证；不要把热风枪设定温度当焊点实际温度。
6. 放大检查后断电测短路，再使用已设好电压与限流的电源上电；先看供电，再检查串口和各模块。

- [ ] 练习板焊点无桥连、方向正确，断电通断检查通过。
- [ ] 返修记录有故障现象、测量、替换件及重新测试结果。
- [ ] DRC 和贴装预览通过，并保存人工复核记录。

## 外观与屏幕交互

用纸稿确定操作，再用 Figma 和 LVGL 把状态做出来。

交付物：三版草图、1:1 界面稿、状态表、LVGL 状态预览与使用观察。

### 先做三版草图，再选一个

1. 画三种桌面摆放方式：平放、倾斜、竖立。标注屏幕、按钮、USB、视线和手指按压方向。
2. 用纸板按预计尺寸折一个体块，让另一人从正常坐姿看屏幕、按按钮、插线；记录挡手、反光、重心和线材拉扯。
3. 从三版中选一个，写清取舍：读取距离、可触达、稳定、可拆装。保留选择理由，以后遇到需求变化可回头判断。
4. 确定文字层级：主状态最大，操作提示其次，调试信息不占用户主要页面；关键状态同时用文字与形状表达，不只靠颜色。

### 把交互写成状态表

| 状态 | 进入条件 | 屏幕与操作 | 退出／失败处理 |
| --- | --- | --- | --- |
| READY | 启动或用户复位 | Ready；Start | 按键进入 RUNNING |
| RUNNING | 收到开始事件 | Working；Cancel | 真实计时完成进入 DONE；取消回 READY |
| DONE | 计时到达且输出成功 | Done；Reset | 确认后回 READY |
| ERROR | 屏幕初始化、配置或外设出错 | 错误原因与重试方式；必要时串口辅助 | 修复后重试，不能假显示完成 |

### Figma：画出能评审的界面

1. 按实际屏幕像素建立 Frame，例如练习使用 240 × 240；另建一块外壳尺寸草图，不把像素直接当毫米。
2. 为 READY、RUNNING、DONE、ERROR 各做一屏，统一文本样式与按钮位置。
3. 原型连线设置 Start、Cancel、Reset 和 Retry；逐条走完成功、取消、失败与重新启动。
4. 把稿件按屏幕实际物理尺寸显示或打印，50 cm 距离检查字号；触屏检查触达，实体按钮则画清楚对应关系。
5. 导出 PNG 作为视觉参考，另保留可编辑源稿和状态表。Figma 稿不会自动变成可运行驱动。

### LVGL 9.4：先跑三态预览

下载本章 C 文件，放入已能显示和接收输入的 LVGL 9.4 项目。先在官方 PC 模拟器或板厂已跑通的屏幕示例上使用。调用 ui_preview_create() 一次；文件只预览状态，Finish 按钮手动模拟完成，不包含真实计时或硬件驱动。

板端前置条件：正确显示驱动和分辨率、绘制缓冲区、刷新完成通知、时钟 tick、timer handler，以及触控／编码器输入。只有显示没有输入时，按钮不会响应。

附带主机自检：使用同一套 LVGL 9.4 配置编译库和此文件，定义 UI_PREVIEW_SELF_TEST 后运行。自检只检查 LVGL 事件与文字状态，不证明真实屏幕、触摸或计时工作。

```sh
# 已有 LVGL 9.4 源码和构建结果时，替换下面两个路径
LVGL_DIR=/path/to/lvgl
LVGL_BUILD=/path/to/lvgl-build
cc -DUI_PREVIEW_SELF_TEST -DLV_CONF_INCLUDE_SIMPLE \
  -I "$LVGL_DIR" ui-preview.c \
  "$LVGL_BUILD/lib/liblvgl.a" -lm -o ui-preview-check
./ui-preview-check
```

1. 在官方模拟器完成构建和默认演示，记录 LVGL 为 9.4。
2. 加入 ui-preview.c，在调用方包含 lvgl.h 并声明 lv_obj_t *ui_preview_create(void);，在显示初始化之后、进入事件循环之前调用一次 ui_preview_create()。
3. 依次点 Start → Finish → Reset，检查 Ready → Working → Done → Ready；Working 期间点 Reset，验证取消返回。
4. 保存截图和观察记录；移植到实际屏幕后重新测输入延迟、刷新与方向。
5. 实际固件删除手动 Finish 按钮，改由真实计时结束事件更新 DONE；屏幕初始化失败走错误处理。不要把演示按钮当产品功能。

- [ ] 非作者能理解 Start、Cancel／Reset、Done 的含义。
- [ ] 成功、取消、失败、断电恢复都有明确入口与反馈。
- [ ] LVGL 预览与真实计时验收分别记录。

## 实体结构、加工与表面

### 从尺寸表建立第一版盒子

以下用一块假设 50 × 30 × 1.6 mm 的占位 PCB 演示建模，不是 ESP32-S3 开发板真实尺寸。板孔、元件最高点、USB 和屏幕位置必须替换为实物测量值。

| 参数 | 练习值 | 使用前确认 |
| --- | --- | --- |
| PCB 长／宽／厚 | 50／30／1.6 mm | 卡尺或厂商 STEP |
| 单侧装配间隙 | 0.4 mm 起步 | 打印测试片校准 |
| 壳壁／底厚 | 2／2 mm 起步 | 材料、打印方向、受力 |
| PCB 下方净空 | 3 mm 起步 | 焊点、线材和定位结构 |
| PCB 上方空间 | 12 mm 起步 | 最高元件与插拔路径 |
| 内腔长／宽 | 50.8／30.8 mm | PCB 尺寸 + 2 × 单侧间隙 |
| 内腔高 | 16.6 mm | 3 + 1.6 + 12，不含顶盖厚度 |

### Fusion／FreeCAD 的可跟做操作

1. 新建设计、单位毫米，保存为 enclosure-v01。建立上述命名参数；插入真实 PCB STEP 或创建占位板体，单独命名 PCB。
2. 新建 Base 零件，在底面草图画居中矩形 54.8 × 34.8 mm，拉伸 18.6 mm。用内腔矩形 50.8 × 30.8 mm 从顶面向下切除 16.6 mm，留下 2 mm 底板。
3. 新建 Lid 零件，画 54.8 × 34.8 mm 顶盖并拉伸 2 mm。首版用独立螺钉或临时固定验证装配，不急着做不可拆卡扣。
4. 测量实际安装孔中心并投影到 Base，建立支撑柱与孔；板无安装孔时设计独立压条，不能凭空在电路板上钻孔。根据螺钉或热熔螺母手册确定柱径和底孔。
5. 在侧面投影真实 USB 插头外轮廓，加单独的插拔间隙参数再切孔；确认包含插头塑料外壳，不只露出金属口。
6. 顶盖按屏幕可视区与模块外形分别建立窗口和支承，按键位置保留手指空间。不要让顶盖直接压屏幕玻璃或排线。
7. 显示装配体，沿实际装入方向检查碰撞与工具空间；保存 STEP 和每个零件的 STL／3MF，重新导入检查毫米单位。

### 先打印局部，再打印整壳

1. 只截取 USB 孔、定位孔、顶盖配合边做小测试片；同批做几个明确标号的间隙候选，例如单侧 0.2／0.3／0.4／0.5 mm。
2. 用计划中的材料、喷嘴、层高和方向切片，检查首层、支撑和螺钉受力方向。
3. 量实际尺寸并试插真实部件，选择能装入又不晃的配合；把补偿记录回参数表。
4. 打印整壳并试装三次：板卡不弯曲、线不夹伤、插头不顶壳、能取出维修。
5. 装上通电板后复测无线、声音和温升；金属、填料和涂层可能改变结果。

### 打磨与涂装的最小练习

先在废料样片上试工艺。粉尘与涂料风险依产品安全数据表选择通风、手套、护目和呼吸防护；活性炭口罩不是所有喷涂的合格防护。没有适合场地时交给专业加工方。

1. 拆出电子件，去支撑和毛刺；遮蔽孔、配合面、螺纹与需要导电接触的位置。
2. 从能消除层纹的砂纸开始，逐级变细；例如 240 → 400 → 800 仅作为样片起点。频繁检查壁厚和边角，防止磨穿或磨松配合。
3. 按材料和底漆说明清洁、干燥并薄涂；需要填补时先在样片确认填料附着。
4. 按涂料说明间隔与固化时间施工，固化后再装配；不要用“摸着干”判断已完全固化。
5. 同光照拍摄样片，记录底材、砂纸、涂料和固化条件；重新量配合面。

### 何时选其他加工

| 工艺 | 适合内容 | 给加工方的文件与检查 |
| --- | --- | --- |
| 激光切割 | 平板面板、垫片 | 带单位 DXF，注明材料厚度；先试切校准切缝；不加工未知或不适合激光的材料 |
| 钣金 | 金属支架、折弯壳体 | STEP + 尺寸图，标板厚、折弯方向和关键尺寸；由供应商确认折弯半径、展开和避让 |
| CNC | 精密孔、金属或工程塑料壳 | STEP + 公差图，内角留刀具半径；只对真正配合面标严格公差 |
| UV 打印 | 面板图文、标识 | 矢量稿／高分辨率图、颜色样、定位基准；在真实材料试印附着与耐擦 |

## 整机联调、升级与 Linux 选修

把软件装进硬件后，按供电、外设、体验、异常恢复逐层验收。

交付物：联调矩阵、功耗实测、固件发布包、恢复步骤；Linux 项目另留移植记录。

### 先冻结一个可复现版本

1. 给 PCB、外壳、固件分别编号，记录开发板、库版本和编译配置；确认工厂交付 PCBA 与设计版本一致。
2. 逐项跑按钮、屏幕、存储、无线等单模块测试；记录型号与日志，再装进外壳。
3. 上电前检查极性、短路、接地和接线应力；使用已设好电压与限流的供电。限流按预期启动电流与元件承受能力选择。
4. 装壳后重复原来的测试，而不是只看能否启动；把新失败与裸板结果对比定位。

### 一张测试矩阵覆盖正常与异常

| 项目 | 操作 | 练习通过条件／记录 |
| --- | --- | --- |
| 启动 | 正常断电再启动 10 次 | 每次回到明确状态；保存启动耗时和日志 |
| 输入与显示 | 20 次按键和状态切换 | 无丢按和重复触发；延迟符合事先设定目标 |
| 供电 | 开屏并执行最重任务，测电源轨 | 电压在器件工作范围；记录启动与工作峰值，无异常复位 |
| 热 | 在记录的室温下连续工作，测热点 | 记录环境／壳体／器件温度与时间；按器件和使用场景限定阈值 |
| 无线（若有） | 装壳前后同位置、同路由器重复测试 | 记录距离、RSSI、断线次数和恢复时间 |
| 稳定性 | 练习先连续跑 2 小时 | 无崩溃和内存持续下降；正式目标另定，2 小时不是寿命结论 |
| 故障恢复 | 断网、错误配置、正常断电恢复 | 显示真实错误并可恢复；没有隐瞒失败的成功状态 |
| 装配 | 多次插拔线、操作按钮、拆装 | 不夹线、不松脱、不压坏屏幕；实际次数留记录 |

### 功耗与续航怎么量

USB 供电练习先记录功耗，不虚构续航。电流表必须串联在正确量程和接口中，不能把电流档直接跨电源；测量前确认仪表保险丝与操作说明。普通 USB 表通常不能准确捕捉短峰值或微安休眠。

1. 分别记录启动、亮屏、任务峰值、待机、休眠的电压／电流／持续时间；必要时用有足够采样率的电源分析工具。
2. 先比较功率：P = V × I；按每种状态所占时间估算平均功率，再测一段真实使用周期。
3. 带电池版本使用保护和充电方案，按电芯、充电芯片与电源路径资料核对边充边用和低压截止；不要直接焊接裸电芯。
4. 示例：电池标称 3.7 V × 1 Ah = 3.7 Wh，假设可用比例 0.8、转换效率 0.85、负载平均 0.4 W，估计约 6.3 小时。这只是练习假设，必须在真实工作周期下放电复测。
5. 续航记录注明亮度、无线状态、环境、截止条件和电池批次；发现偏差先检查电源损耗与占空比。

### 固件发布与 OTA 恢复演练

1. 先保留稳定版二进制、源码提交号、分区表、编译版本及校验值，写明适配 PCB 版本与有线恢复方式。
2. 无需联网升级的产品先使用有线升级，并验证用户能识别版本和完成升级；需要 OTA 时采用框架官方流程。
3. ESP-IDF OTA 使用合适的分区布局和回滚配置；下载通道验证服务器身份，升级包验证真实性与硬件兼容性。
4. 新固件启动后完成真实自检再确认版本有效，失败时触发框架回滚。不要在进入 main 时立即把所有版本标为成功。
5. 在可恢复的测试板上分别演练下载中断、错误包和新版自检失败；保留日志并验证能回到稳定版。只测试中断应用升级，不随意破坏 bootloader 或分区表。
6. 发布包附版本、变更、已知问题、升级步骤、校验值和恢复步骤；量产前再验证一次。

- [ ] 正常升级和失败回滚分别有证据。
- [ ] 每一台能读出硬件与固件版本。
- [ ] 用户数据保留／迁移策略已经说明，并实际测试。

### Linux 选修：先辨认系统，再移植

仅在使用树莓派／Linux 主板时学习。MCU 项目不需要为了路线图而换成 Linux。设备树描述硬件与资源，驱动负责具体操作；不同板的 DTB、内核和引脚不能混用。

```sh
uname -a
cat /etc/os-release
ls /dev/tty*
ls /sys/bus/i2c/devices
dmesg | tail -n 60
```

1. 在目标板运行以上只读命令，记录系统、内核与设备枚举；无权读 dmesg 时按系统权限处理。学习 pwd、ls、cd、cat、cp 和日志定位。
2. 先用厂商镜像与官方外设示例点亮屏幕，再决定是否自编内核；确认屏幕控制器、总线、供电、reset、背光与分辨率。
3. 交叉编译先做 hello world：从板厂获取匹配架构与 libc 的工具链／sysroot，用对应编译器构建，通过 file 检查架构，再拷到目标板运行。不要只在电脑上运行就算通过。
4. 需要设备树修改时，从准确板型的源码与 overlay 示例开始，按对应 binding 核对 compatible、reg、GPIO 和时序；编译、备份可启动镜像，再按厂商方式应用。
5. 先查内核是否已有对应驱动；只在确实缺失时做驱动适配。看 probe 日志和总线设备绑定，再检查 DRM／framebuffer、输入事件与屏幕刷新。
6. 最后部署应用与启动服务，测试权限、启动顺序、退出重启和断电恢复；还原原镜像的步骤必须可用。

- [ ] hello world 在目标板执行。
- [ ] 冷启动能枚举目标外设，显示与输入真实工作。
- [ ] 系统、内核、设备树、驱动和应用版本均留档。

参考来源：[ESP-IDF OTA 与回滚](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/system/ota.html) · [Linux 设备树模型](https://docs.kernel.org/devicetree/usage-model.html) · [Linux 平台驱动模型](https://docs.kernel.org/driver-api/driver-model/platform.html)

## 产品摄影、视频与宣发

让陌生人看懂产品能做什么，并区分真实演示与渲染。

交付物：六张实拍图、30 秒演示、产品页文案、说明书和素材授权记录。

### 搭一个够用的拍摄台

1. 先用已有手机或相机、稳定支架、干净背景与柔和窗光；是否购买镜头和灯光，由现有画面问题决定。
2. 关闭混杂色温的光源，主体离背景留距离；用白卡补暗面，调整光源位置避免屏幕和外壳强反光。
3. 固定构图、曝光与白平衡，屏幕单独检查过曝和频闪；出现条纹时调整快门、屏幕亮度或拍摄方式并回放确认。
4. 相机拍摄关注焦距对透视和工作距离的影响；小细节才需要近摄能力。先确认普通镜头或手机近摄能否满足。
5. 拍摄包含真实使用动作的测试片，放大看对焦、字样和噪点；确认后批量拍。

## 小批量制造、成本与售后

从已验收样机进入小规模交付，先控制版本和逐台质量。

交付物：生产 BOM、试产记录、测试 SOP、成本表、包装清单与售后台账。

### 从首件到小批量

1. 冻结硬件、固件、结构与物料版本；BOM 写准确厂商料号、数量、替代规则和供货来源。替代元件先验证再批准。
2. 先做首件确认文件、工艺与装配；再做小批试产，例如 5–10 台，数量根据成本和风险选择。不要把示例数量当通用规则。
3. 向供应商确认来料、生产、抽检、返修与交期；首次合作保留确认样和制造文件版本。
4. 试产统计一次通过率、返修原因、每台工时和报废；重复故障未解决时不要扩大数量。
5. 用稳定试产结果决定下一批，并预留备件和返修产能；小批也要逐台做核心功能测试。

### 做一个最小测试治具

优先用定位底座、已确认接线的连接器和固定测试固件。只有频繁插拔拖慢生产时，再换 pogo pin 弹簧针。测试点和供电顺序必须与准确 PCB 版本匹配。

1. 在 PCB 设计时留 GND、电源、烧录和关键测试点；设计方向定位，防止反放或针脚短接。
2. 底座固定板的位置，针床或线束保持应力释放；接触顺序与防护按实际电路确认。
3. 使用已知良品和一块可安全模拟故障的测试板，验证治具既能判通过，也能检出指定故障。
4. 先读序列号与版本，再烧录目标固件；检查固件校验与版本，运行按钮、显示、供电、无线等实际存在的测试项。
5. 把测量值、限值、测试程序版本、操作员和时间写入逐台记录；任一必测项失败就隔离，返修后重新测试。
6. 每日开工用已知良品检查治具接触与测量；“显示 PASS”必须来自测试结果，不能只表示烧录成功。

### 成本和定价练习

下面全部是教学假设，不是采购报价或定价建议。按不含税示例口径计算；真实销售要把实际税费、平台计费方式、运费承担和退换货成本补入表。

| 项目 | 示例人民币／台 | 如何得到实际值 |
| --- | --- | --- |
| PCBA | 65 | 订单总额分摊到合格数量 |
| 外壳 | 20 | 材料、加工、表面与损耗 |
| 线材／紧固件 | 8 | 生产 BOM |
| 装配／测试人工 | 15 | 实测每台工时 × 工时单价 |
| 包装 | 6 | 包装清单与报价 |
| 物流 | 8 | 实际目的地和渠道 |
| 返修／损耗预留 | 8 | 试产与售后数据修正 |
| 合计变动成本 C | 130 | 上述项目相加 |
| 固定投入 F | 1500／批 | 治具、打样等；另决定分摊 |
| 练习销量 Q | 50 台 | 教学假设 |
| 固定成本分摊 | 30／台 | F / Q |
| 示例费用率 r／目标结余率 m | 5%／25% | 仅为计算练习 |
| 示例售价 P | 约 228.57 | (C + F/Q) / (1-r-m) |

### 算清盈亏，再决定数量

1. 先把成本按变动与固定分开，确保人工、返修和包装没有漏项。
2. 本例 P = 160 / 0.70 ≈ 228.57；使用 229 元演算时，单台贡献 = 229 × 0.95 − 130 = 87.55 元。
3. 固定投入 1500 元的回收点为向上取整 1500 / 87.55，即 18 台；这未包含例外成本、税费或销售风险。
4. 若分母 1-r-m ≤ 0 或单台贡献 ≤ 0，当前假设无可行解，应修改成本或价格假设。实际利润仍按实际收入、费用和损耗计算。
5. 把乐观、基准、保守销量各算一次，检查现金先支出但库存尚未卖出的压力。

### 包装、交付与售后闭环

1. 包装 BOM 列设备、线材、说明书、标签、缓冲材料和外箱；注明数量、尺寸与装箱方向。
2. 根据产品风险做运输包装试验，记录条件与结果；电子板防静电、易损结构有支撑，随箱电池按承运方当前要求确认。
3. 序列号贴到设备、包装和台账；出货前清除测试账号、测试网络等信息，确认生产配置与固件版本。

5. 售后接单先记录序列号、故障现象、版本与复现步骤；涉及供电异常的设备先停止使用，隔离检查。

# 硬件入门 Starter Kit

面向没有硬件经验的参与者。

## 一、每人基础套件

预算约 **¥150–220 / 人**。

| 零件 | 推荐型号 | 数量 | 用途 |
|---|---|---:|---|
| 开发板 | ESP32-S3-DevKitC-1-N8R8 | 1 | 主控制器、Wi-Fi、蓝牙 |
| 面包板 | 830 孔面包板 | 1 | 无需焊接连接电路 |
| USB 线 | USB-C 数据线 | 1 | 供电、烧录程序 |
| 杜邦线 | 公公、公母、母母 | 各 10 | 连接模块 |
| LED | 红、绿、蓝 | 各 2 | 最基础输出 |
| 电阻 | 220Ω、1kΩ、10kΩ | 各 5 | LED 和输入保护 |
| 按钮 | 面包板轻触按钮 | 2 | 用户输入 |
| 电位器 | 10kΩ 旋钮 | 1 | 模拟量输入 |
| 温湿度 | BME280 模块 | 1 | I²C 传感器练习 |
| 距离传感器 | VL53L0X 模块 | 1 | 手势、接近检测 |
| RGB 灯 | WS2812B 八位灯环 | 1 | 状态和情绪反馈 |

## 二、AI 多模态扩展包

每组配置一套即可。预算约 **¥300–450 / 组**。

| 零件 | 推荐型号 | 数量 | 用途 |
|---|---|---:|---|
| 麦克风 | INMP441 I²S 模块 | 1 | 采集语音 |
| 音频功放 | MAX98357A I²S 模块 | 1 | 驱动喇叭 |
| 喇叭 | 4Ω 3W 全频喇叭 | 1 | 播放语音和提示音 |
| 显示屏 | 2.4 英寸 ILI9341 SPI 240×320 | 1 | 显示界面和结果 |
| NFC | RFID-RC522 / PN532 模块 | 1 | 签到、身份绑定、触碰交互 |
| microSD | 32GB | 1 | 保存图片、音频和配置 |

**不需要另外购买「语音识别模块」。** 入门阶段由 INMP441 录音，ESP32-S3 将语音发到电脑或云端 AI，再通过 MAX98357A + 喇叭播放回复。

## 三、工作坊备选：集成开发板

若目标是 **2 小时工作坊**、希望少接线，可考虑 **立创实战派 ESP32-S3** 一类集成板（屏 / 麦 / 喇叭 / IMU 已在板上）。面包板基础包仍适合「电子基础实验」关卡。

## 四、采购提示

- 核对具体 SKU、版本、接口电平与数据手册
- USB 线必须支持**数据传输**（不是只能充电）
- 第一次上电前先读 [安全规则](safety.md)
- 接线约定见 [wiring.md](wiring.md)

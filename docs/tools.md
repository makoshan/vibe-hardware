# 工具平台地图

每个阶段只讲 **一个默认工具**，其余放进阶。

| 阶段 | 默认平台 | 进阶选择 |
|---|---|---|
| 需求和交互 | Figma | FigJam |
| 固件 | Arduino IDE | ESP-IDF、PlatformIO |
| 离线语音 | ESP-SR | 联网语音模型 |
| 原理图和 PCB | 嘉立创 EDA 专业版 | KiCad |
| PCB 生产 | 嘉立创 PCB、SMT | 其他板厂 |
| 图形化结构建模 | Fusion 360 | FreeCAD、Onshape |
| AI 参数化建模 | build123d | CadQuery |
| 切片打印 | Bambu Studio | OrcaSlicer |
| 版本管理 | GitHub | 国内 Git 平台 |

## 推荐讲法（分享 / 工作坊）

1. 需要购买的工具和 Starter Kit  
2. 电压、GPIO、I²C、SPI、UART 基础  
3. ESP32 + 面包板原型  
4. 原理图与 PCB 设计平台  
5. 嘉立创打板和贴片  
6. Figma 产品与界面  
7. Fusion / FreeCAD / Onshape 建模  
8. 3D 打印、装配、验收  

## 时长边界

- **30 分钟分享**：PCB / CAD 只讲流程，不承诺教会  
- **2 小时工作坊**：集成板或面包板，跑通传感器 / 屏 / 语音链路  
- **一天 PCB 工作坊**：才适合自己画板并下单  
- **可佩戴产品**：电池安全、充电、功耗、公差另开项目

# 工具平台地图

每个阶段只讲 **一个默认工具**，其余放参考。

| 阶段 | 默认平台 | 进阶选择 |
|---|---|---|
| 需求和交互 | Figma | FigJam |
| 固件 | Arduino IDE | ESP-IDF、PlatformIO |
| 离线语音 | [ESP-SR](https://github.com/espressif/esp-sr) | 联网语音模型 |
| 原理图和 PCB | 嘉立创 EDA 专业版 | [KiCad](https://docs.kicad.org/) |
| PCB 生产 | 嘉立创 PCB、SMT | 其他板厂 |
| 图形化结构建模 | Fusion 360 | FreeCAD、Onshape |
| AI 参数化建模 | [build123d](https://build123d.readthedocs.io/en/stable/) | CadQuery |
| 切片打印 | Bambu Studio | OrcaSlicer |
| 版本管理 | GitHub | 国内 Git 平台 |

## 推荐讲法

1. 工具与 [Starter Kit](starter-kit.md)  
2. 电压、GPIO、I²C、SPI、UART  
3. ESP32 + 面包板 / 集成板原型  
4. 原理图与 PCB 平台  
5. 嘉立创打板和贴片  
6. Figma  
7. Fusion / FreeCAD / Onshape  
8. 3D 打印、装配、验收  

完整七步见 [路线图](roadmap.md)。时长边界见 [资源 · 风险](resources.md#5-风险与触发条件)。
